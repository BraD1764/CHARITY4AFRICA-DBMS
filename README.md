A comprehensive database management system for CHARITY 4 AFRICA, a government initiative managing household item donations to charity stores. This is a class exercise that demonstrates the transition from a flat file system to a relational database.

Manages customers, employees, donators, donations, deliveries, returns, and invoices
Generates reports on customer spending, deliveries, and returns
Implements business rules (customer ratings, delivery time calculations)
Handles errors with both system-defined and user-defined exceptions
Auto-generates IDs for new records

Database: SQL Server
IDE: SQL Server Management Studio (SSMS)
Language: T-SQL
